🔧 About

Roots Auto Doctor is a modern Windows diagnostic application designed to communicate with vehicles through OBD interfaces.

The project aims to provide a simple and intuitive way to detect interfaces, communicate with ECUs and access vehicle diagnostic information.

────────

⚙️ Main Features

• OBD interface detection
• COM port scanning
• Vehicle communication
• ECU diagnostics
• Fault code reading
• Vehicle data access
• Modern and simple interface

────────

🛠️ Built With

Python • .NET • Windows • OBD-II
